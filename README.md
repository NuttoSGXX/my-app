# ตารางคิวเซสชัน (Vercel)

ไฟล์
- index.html       หน้าเว็บ (ลูกค้าดู / ผู้ดูแลลงคิว)
- api/schedule.js  ฟังก์ชันฝั่งเซิร์ฟเวอร์ (อ่าน/บันทึก + ตรวจรหัสผู้ดูแล)
- package.json

อัปเดตจากเวอร์ชันเดิม
- แทนที่ index.html และ api/schedule.js ใน repo เดิม แล้ว push ขึ้น GitHub — Vercel จะ deploy ให้เอง
- ไม่ต้องตั้งค่าใหม่ ใช้ Redis และ ADMIN_PIN ตัวเดิม
- คิวเดิมแบบ เช้า/บ่าย/ค่ำ ถูกแปลงเป็นรูปแบบใหม่ให้อัตโนมัติ (ช่วงที่ไม่มีชื่อแคมเปญจะกลายเป็น "ไม่ว่าง")

ตั้งค่าครั้งแรก (ถ้ายังไม่เคยทำ)
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub แล้วสร้างโปรเจกต์ใหม่บน Vercel จาก repo นั้น
2. Storage / Marketplace -> Upstash for Redis -> สร้าง -> Connect to Project
3. Settings -> Environment Variables -> ADMIN_PIN = รหัสผู้ดูแล
4. Redeploy หนึ่งครั้ง

วิธีใช้
- กด "BY DM BANK" มุมล่างซ้าย 8 ครั้ง -> ใส่รหัส -> คลิกที่วันเพื่อลงคิว
- แต่ละวันลงได้สูงสุด 8 คิว: เวลาเริ่ม-จบ, ประเภท (Campaign / Mini-series / One-shot / ไม่ว่าง), ชื่อแคมเปญ, SS, @discord ผู้เล่น, โน้ตส่วนตัว
- โน้ตส่วนตัวไม่ถูกส่งให้ลูกค้าเลย; @discord ผู้เล่นจะแสดงให้ลูกค้าเห็นก็ต่อเมื่อเปิดสวิตช์ในแถบผู้ดูแล
